# TOKEN ECONOMY — NIVEAU 02 — AMBIGUÏTÉ COGNITIVE

# PROBLÈME MAJEUR

Le vrai coût IA vient souvent :
- des concepts flous
- des formulations ouvertes
- des espaces d’interprétation implicite

Exemple dangereux :

```txt
surprise culturelle
```

Une IA doit :
- interpréter
- contextualiser
- arbitrer
- comparer
- déduire

➡️ coût cognitif énorme.

---

# SOLUTION

Transformer progressivement :

```txt
concept flou
```

→

```txt
taxonomy fermée
```

Exemple :

❌

```txt
surprise culturelle
```

✅

```txt
PAYOFF_TYPE:
- collision
- oralité
- disproportion
- faux_reflexe
- révélation
```

---

# TOKEN ECONOMY — NIVEAU 03 — DUPLICATIONS SÉMANTIQUES

# PROBLÈME

Même sans duplication texte,
la duplication de concepts coûte énormément.

Exemple :

```txt
anti-school-feeling
```

présent dans :
- A1
- A3
- A3_RUNTIME_SIGNALS
- A4_RUNTIME_BALANCE

L’IA doit constamment :
- fusionner
- arbitrer
- maintenir plusieurs contextes similaires

➡️ inflation cognitive massive.

---

# SOLUTION

Créer :

```txt
FACTORY_RUNTIME_LEXICON.md
```

Contenu :
- définitions officielles
- taxonomies runtime
- IDs gameplay
- tags universels
- vocabulaire fermé

Puis :
- références courtes partout ailleurs
- disparition des répétitions conceptuelles.

---

# TOKEN ECONOMY — NIVEAU 04 — TAGS VS PROSE

# PROBLÈME

- en phrases

- en formulations humaines.


# SOLUTION

