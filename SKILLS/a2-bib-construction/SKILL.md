# A2 — BIB CONSTRUCTION

**Rôle :** Créer base items brute thématique depuis recherche/brainstorm.

---

## WHEN TO USE

- Démarrer nouveau quiz (thème)
- A1 contexte disponible (thème, public, scope)

## PROCESS

| Étape | Action | Output |
|-------|--------|--------|
| 1 | Charger A1_THEME contexte | Scope clair |
| 2 | Brainstorm items bruts (min 500+) | Candidats hétérogènes |
| 3 | Organiser par sections thématiques | BIB structurée |
| 4 | Coter difficulté brute (1-5) | Niveaux assignés |
| 5 | Documenter sources | Traçabilité |
| 6 | Output A2_BIB_[THEME]_NN.txt | Brut, non modifié après |

## REGLES

[RULE-A2-001] BIB = source inviolable après archivage
[RULE-A2-002] Pas de filtrage (brut)
[RULE-A2-003] Min 2× stock cible (oversampling)

## EXEMPLE

```
## SECTION: LÉGENDES ANNÉES 1960s

CDM_PIONNIERE_EUSEBIO_001 (Diff: 3)
- Portugal, attaquant, WC 1966
- Meilleur buteur

CDM_PIONNIERE_RONALDO_002 (Diff: 2)
- Brasil, tous temps, records
```
